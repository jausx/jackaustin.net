## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or

```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Adding a project

Drop a markdown file in `content/projects/` (filename becomes the URL slug) and push; Netlify rebuilds.

```md
---
title: My Project
date: 2026-01-31
summary: One-line description shown on the projects grid.
cover: /games/my_project.png   # file under public/
links:
  - label: itch.io
    url: https://example.itch.io/my-project
draft: false                   # true hides it everywhere
---

Body in markdown. Raw HTML (iframes, itch widgets, images) works too.
```

Content is read only through `src/lib/projects.ts`, so swapping to a CMS later means reimplementing `getAllProjects` / `getProject`.
